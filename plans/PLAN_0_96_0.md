# v0.96.0 Implementation Plan — Defaults, Bounds & Diagnosis

This plan keeps v0.96.0 on top of existing configuration, refresh history,
health-check, and ACL machinery. It adds SQL surfaces only where an existing
surface cannot report the contract.

## Work queue

1. PP-1 — derive an effective profile from PostgreSQL settings and discoverable
   host limits; expose the evidence through `active_profile()`.
2. PP-2 — expose per-stream disk usage and resource enforcement classes through
   `disk_usage()` and `health_check()`.
3. PP-3 — expose a stable progress view backed by refresh history.
4. PP-4 — document the stable reason-code/SQLSTATE/detail/hint contract and
   add a machine check for SQL-facing error identifiers.
5. PP-6 — create the three NOLOGIN roles and grant existing lifecycle,
   operator, and diagnostic privileges without adding a second authorization
   layer.

## Release artifacts

- Add the 0.95.0 → 0.96.0 upgrade SQL and archive install SQL.
- Bump Cargo, metadata, lockfile, image defaults, and upgrade-test defaults.
- Update the changelog and mark the roadmap release after the gates pass.
